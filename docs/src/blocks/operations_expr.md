# Arithmetic Expression

Selects the operator for an arithmetic expression. Can be extended for longer operations.

There are 7 arithmetic operators available: `+`, `-`, `*` `/`, `%`, `**` and `=`.

![Example of arithmetic operation](../images/operations_expr_example.png)

and would produce the following Essence Output:

```essence
0 + 2 - 1 ** 5
```

See [here](https://conjure.readthedocs.io/en/latest/essence.html#arithmetic-operators) for further information surrounding arithmetic operators.
