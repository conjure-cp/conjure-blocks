# Matrix

An example of a domain constructor. The matrix block takes a list of domains for its indices and a domain for the 
entries of the matrix. Matrices can be of arbitrary dimensionality (greater than 0). 

In Conjure Blocks, a matrix can be indexed only by integer or Boolean.

See [here](https://conjure.readthedocs.io/en/latest/essence.html#matrix-domains) for further information surrounding 
matrix domains.
